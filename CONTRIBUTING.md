# Contributing to Konek

First off, thank you for considering contributing to Konek! It's people like you that make open-source such a fantastic community to learn, inspire, and create.

## 🤝 How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub. Before creating a new issue, please check the existing issues to ensure it hasn't already been reported.

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues. Please provide a clear and detailed explanation of the feature you'd like to see, and why it would be beneficial.

### Pull Requests
1. **Fork the Repo**: Click the "Fork" button at the top right of this page to create your own copy.
2. **Create a Branch**: `git checkout -b feature/your-feature-name` or `bugfix/issue-number`.
3. **Commit your Changes**: Use clear, conventional commit messages (e.g., `feat: added custom contact icon upload`).
4. **Push to your Branch**: `git push origin feature/your-feature-name`.
5. **Open a Pull Request**: Go to the original repository and click "Compare & pull request".

## 🧑‍💻 Coding Standards
- We use **Prettier** for formatting. Run `npm run format` before committing.
- We use **ESLint** for code quality. Run `npm run lint:fix` to resolve issues automatically.
- Keep components small and focused.
- Ensure any new features work seamlessly on mobile, tablet, and desktop layouts.

Thank you for contributing! 🚀
